# Catch — Implementation Roadmap (12 Weeks)

## Phase 1: Foundation (Weeks 1–2)

- [ ] Complete `TRACKING-SETUP.md` in full — verify test purchase fires correctly on both platforms
- [ ] Build Google product feed per `CAMPAIGN-ARCHITECTURE.md` feed hygiene rules (titles, images, custom labels for margin/best-seller)
- [ ] Set up campaign structure on both platforms per `CAMPAIGN-ARCHITECTURE.md` (don't launch yet)
- [ ] Build initial audiences: Meta lookalikes (need existing purchaser data — pull from Shopify/store), Google Customer Match if 90-day history + prior spend threshold is met (otherwise skip for now)
- [ ] Produce P1–P2 creative from `CREATIVE-BRIEF.md` (Set bundle hero video + static product/lifestyle images) — this is the launch-blocking creative, don't launch on renders alone if video isn't ready
- [ ] Route Collagen Shot and Sunscreen copy through the claims documents for review — do not let this block Core Line / Set launch; these two can follow in Week 3–4

## Phase 2: Launch (Weeks 3–4)

- [ ] Launch Google Brand Search + PMax (Best Sellers, Pairing Sets, Core Lines) with Maximize Clicks/Conversions bidding (volume too low for Target CPA yet)
- [ ] Launch Meta Advantage+ Sales Campaign with Lowest Cost bidding
- [ ] Launch Collagen Shot and Sunscreen campaigns once claims-reviewed copy is locked (separate campaigns, not blended into Core Line/Set traffic)
- [ ] Set conservative daily budgets — full Month 1 budget from `BUDGET-PLAN.md`, but do not touch anything for the first 7 days
- [ ] Daily monitoring for tracking accuracy (not performance optimization yet) — is Purchase firing, is EMQ populating, is PMax pulling the right feed data

## Phase 3: Optimize (Weeks 5–8)

- [ ] After 2+ weeks of data: apply the 3× Kill Rule to any ad set/ad group at >3x target CPA with 0 conversions
- [ ] Tighten Google Search negatives based on search term report
- [ ] Move to 70/20/10 budget allocation (Proven = Best Sellers/Core Lines, Scaling = Pairing Sets, Testing = Collagen Shot/Sunscreen/new formats)
- [ ] Begin A/B testing: creative (P3–P4 from `CREATIVE-BRIEF.md`), audiences, and landing page if CVR is below the 3.68 Google / category benchmark
- [ ] Re-evaluate bidding strategy against the conversion-volume table in `CAMPAIGN-ARCHITECTURE.md` — move to Target CPA/ROAS once thresholds are met

## Phase 4: Scale (Weeks 9–12)

- [ ] Apply the 20% Rule to confirmed winners (max +20% per increase, 3–5 days between increases)
- [ ] Roll Testing-tier winners (e.g., a Collagen Shot creative angle that's working) into the Scaling tier
- [ ] First monthly performance review against `ADS-STRATEGY.md` KPI targets (Month 3 column)
- [ ] Decide whether a 3rd platform (TikTok is the natural next add for this category) is warranted based on MER and whether Meta/Google are hitting Month 3 targets — don't add a 3rd platform before the first two are profitable

## Ongoing

- [ ] Quarterly 70/20/10 rebalance
- [ ] Creative refresh every 2–4 weeks on Meta (frequency >4.0 is the trigger, not the calendar)
- [ ] Q4 prep starts in September: 40–60% budget increase plan, creative testing front-loaded, gift-Set framing locked before October
